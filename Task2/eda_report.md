# Exploratory Data Analysis Report

## 1. Introduction

This project performs Exploratory Data Analysis (EDA) on a customer sales dataset.
The analysis uses Python and Pandas to understand customer demographics, purchasing
patterns, product performance, and sales trends.

## 2. Dataset Overview

The dataset contains customer information such as:

- Customer ID
- Name
- Age
- Gender
- City
- Product
- Quantity
- Price
- Purchase Date

## 3. Analysis Performed

The following analyses were performed:

- Descriptive statistical analysis
- Product-wise sales analysis
- City-wise sales analysis
- Product quantity analysis
- Customer age distribution
- Outlier detection
- Business insights

## 4. Key Findings

The analysis helps identify:

- Products generating higher sales
- Products with higher purchase quantities
- Cities with higher purchasing activity
- Distribution of customer ages
- Unusual values or potential outliers

## 5. Conclusion

The EDA provides useful insights into customer purchasing behavior and product
performance. These findings can help businesses understand their customers,
identify popular products, and make better data-driven decisions.
